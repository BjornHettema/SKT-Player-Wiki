# Storm King's Thunder - Player Wiki

The players' shared knowledge base: session recaps, characters, the people and places the party has met, and handouts.

**Golden rule: everything in this vault is something the players are allowed to know.**
No book text, no DM secrets, no PC secrets. If in doubt, leave it in the DM vault.

A note with `draft: true` in its properties stays hidden when the site is published.
